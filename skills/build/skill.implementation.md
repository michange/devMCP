# @implementation — write the minimal runtime change

Read the accepted TDD list and the RED evidence. Write only the runtime code required
to satisfy those tests and the accepted contract. Do not change tests, weaken
assertions, add unrelated behavior, or expand the filesystem projection.

Return a behavioral discovery that changes the accepted contract, architecture, or
test plan to Design Dialogue. Leave test execution to `@green` after
`@matchConventions` has checked the implementation.
